One original line of plain text, at most 200 characters: a review of planet Earth left by an alien tourist.

> 1/5 stars. The creatures queue 40 minutes to photograph the sunset, then crawl home in metal boxes for two hours. Beautiful light. Would not return.

## Run

```sh
python3 main.py
```

`main.py` gates the line (one line, 1–200 chars, not whitespace-only), writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), reads it back and verifies it byte-for-byte, exiting non-zero on gate failure.
